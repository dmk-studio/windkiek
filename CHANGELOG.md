# Changelog

## 1.0.0 – 2026-10-25

First public version.

- 4-day wind forecast (08–20 h, every 3 hours) for up to 6 spots, two per page
- Black bar when the minimum wind and a rideable direction match, per spot
- Setup on the phone: setup WiFi with QR code, settings page with place search, map,
  compass rose for wind directions, minimum wind, coastal grid point
- Languages DE/EN/NL, units kn, m/s, km/h, Bft, update every 1–4 hours
- Middle key 3 s: settings, 10 s: factory reset
- Web installer and website (GitHub Pages)
