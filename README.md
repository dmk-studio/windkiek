# Windkiek for the reTerminal E1001

[Deutsch](README.de.md)

Free open-source firmware that turns the **Seeed reTerminal E1001** (ESP32-S3, 7.5" black-and-white ePaper)
into a wind forecast display for kite, windsurf and sailing spots.
*Kieken* is Low German for "to take a look": Windkiek is the quick look at the wind.

- 4-day forecast, every 3 hours from 08 to 20 h: wind as bars, gusts as a line, weather, direction, temperature
- **Black bar** = minimum wind reached **and** the wind comes from a rideable direction (set per spot)
- Up to 6 spots, two per page, left/right keys switch pages
- Setup on the phone: no app, no account, no programming
- Languages DE / EN / NL, units kn, m/s, km/h, Bft
- Runs on battery: deep sleep between updates (every 1–4 h)
- Weather data from [Open-Meteo.com](https://open-meteo.com) (CC BY 4.0), model "best match"

**Website and web installer:** https://dmk-studio.github.io/windkiek/

## Installation

### In the browser (recommended)

1. Open the website in Chrome or Edge on a computer.
2. Connect the reTerminal E1001 with a USB-C data cable.
3. Click **Install** and choose the port (usually "USB-SERIAL CH340").

The original firmware (SenseCraft HMI) is replaced. Seeed explains how to restore it in the
[SenseCraft HMI documentation](https://sensecraft-hmi-docs.seeed.cc/en/guides/firmware-update).

### With PlatformIO

```bash
pio run -t upload
```

## Setup

1. After the installation the display shows a QR code. Scan it, or join the WiFi `Windkiek-Setup`.
2. On the page that opens, choose your home WiFi (2.4 GHz) and enter the password.
3. The display connects and shows a second QR code. Switch your phone back to your home WiFi and scan it
   (or open `http://windkiek.local`).
4. Add your spots: search a place or set it on the map, tap the rideable directions on the compass rose,
   choose the minimum wind, tick "coastal spot" for spots at the sea. Save.

| Key | Action |
|---|---|
| Left / right | Previous / next page |
| Middle | Update now |
| Middle, hold 3 s | Settings page (LED lights up) |
| Middle, hold 10 s | Factory reset (LED blinks) |

If the WiFi cannot be reached three times in a row, the display opens the setup WiFi for 3 minutes.

## Project structure

| Path | Content |
|---|---|
| `src/main.cpp` | Flow per wakeup: keys, setup, WiFi, update, drawing, deep sleep |
| `src/render.cpp` | Screen layout (all screens) |
| `src/icons.h` | Weather icons |
| `src/forecast.cpp` | Open-Meteo request and parsing |
| `src/settings.cpp` | Settings in flash (NVS), JSON for the settings page |
| `src/portal.cpp` | Setup WiFi, captive portal and settings page server |
| `src/text.cpp` | Display texts DE/EN/NL, unit conversion |
| `src/power.cpp` | Battery, LED, keys, deep sleep |
| `src/fonts.h` | Inter as 1-bit fonts, generated by `tools/fontconv.py` |
| `include/config.h` | Fixed parameters: version, time slots, timeouts, pins |
| `web/setup.html` | Settings page for the phone, embedded into the firmware at build time |
| `site/` | Website with live preview and web installer (GitHub Pages) |
| `tools/preview.html` | Layout preview in the browser with live data |
| `tools/mock_device.py` | Simulates the device API to work on `web/setup.html` |

More details: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)
